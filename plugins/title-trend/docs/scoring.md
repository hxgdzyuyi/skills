# 确定性评分公式

公式版本：**bing-monthly-v1.0.0**。实现：`src/title_trend/scoring.py`。这是可解释的启发式参考，未以微信公众号阅读量或点击率校准。

## 来源、粒度与共同时间窗

只使用 DataForSEO Bing Search Volume History 的月度次数。真实请求指定地区、`zh-CN` 和 desktop/mobile/tablet/non_smartphones 四类设备；每月搜索量为四类设备次数之和。未提供某设备或月份不补零，整月为 null。返回重复月份、非法日期、负数、浮点量或大于 10^12 的次数时拒绝该关键词数据。广告竞争缺失不影响评分，保持 null。

从 Bing Status 的 `last_year_in_monthly_searches` 和 `last_month_in_monthly_searches` 取来源最新月，再与本机当前月的前一个月取较早值，称为 M。查询与报告保存 M，评分函数显式接收确定的日期参数。所有关键词使用同一个 M，不挑选每词最有利窗口。按自然月计算，当前月及未来月不参与评分。来源 M 若早于当前月减两个月，停止评分；允许常规一个月延迟以及最多再延迟一个月。

完整基线 H 为 M-11 至 M 共 **12 个连续完整月**。近期 R 为 M-2 至 M（3 月），前期 P 为 M-5 至 M-3（3 月）。不是同比，季节性仍可能影响结果。请求使用接口默认最多 24 月历史，不传自定义 date_from/date_to，再由 Python 选固定 12 月窗口。

## 变量

对于每个候选关键词 k：

| 变量 | 定义 | 单位/常数 |
|---|---|---|
| v_i | H 中每个月四类设备合计搜索次数 | 次/月，非负整数 |
| r | R 中三个 v_i 的算术平均 | 次/月 |
| p | P 中三个 v_i 的算术平均 | 次/月 |
| V | 需求归一化的固定上限 | 100000 次/月 |
| B | 增长的固定低基数下限 | 100 次/月 |
| d | `(r - p) / max(p, B)` | 无量纲，供增长评分 |
| c | `min(1, r / B)` | 无量纲，低需求抑制系数 |

所有常数和权重与关键词集合无关。不会对当前最多五个关键词做 min-max 归一化。

## 三个分项与关键词分

搜索需求 D：

```
D = 100 × ln(1 + min(r, V)) / ln(1 + V)
```

自然对数，r=0 时 D=0，r≥100000 时 D=100；原始量不被改写。

趋势热度 T（近期均值在该词自身十二个单月量中的经验位置）：

```
T = 100 × [count(v_i < r) + 0.5 × count(v_i = r)] / 12
```

严格相等按整数/确定的均值处理，重复值使用中间秩。正量且水平恒定时 T=50。r=0 时单独设 T=0，避免全零或近期零值被解释为热度。该分项不是 Google Trends 指数，也不是公众号指数。

增长 G：

```
G = 50 × [1 + clip(d, -1, 1)] × c
clip(x,a,b) = max(a, min(b,x))
```

p≥100 且 r=p≥100 时 G=50；降低到零时 G=0；以足够基数增长 100% 及以上封顶 100。p=0 时分母使用 B，不出现无穷大；r<100 时用 c 抑制低量噪声。p=0、r=10 时 d=0.1、c=0.1、G=5.5。负增长保留，d 最低裁到 -1。

关键词分 S_k：

```
S_k = 0.40 × D + 0.30 × T + 0.30 × G
```

如果 H 十二月全为真实零值，明确返回 D=T=G=S_k=0（有效数据，不是缺失）。各分项均在 0–100 内，组合也在此范围；范围并不保证每个整数端点在常见数据中可达。原始十二月量没有异常值删点或动态校准；固定 D/G 裁剪控制极大值影响，T 依赖秩次。输入校验上限之外的数据停止评分。

用于展示的原始增长率：p>0 时 `100 × (r-p)/p`，单位百分比；p=0 时为 null，不把从零增长显示为无限大。它与 G 不同，不限幅，可很大。零与零的原始百分比同样 null。

## 标题聚合、覆盖与显示

当前 Agent 选择 1–5 个唯一候选短语，n 为去重后的候选数。**所有 n 个关键词**必须有可评分数据，包括同一 12 月窗口、完整设备、来源状态足够新且缓存未过期。否则标题分和标题分项全为 null，UI 显示“数据不足，暂不评分”。不删除没有数据的候选以抬高综合分，n=0 也不评分。

满足覆盖时使用等权均值：

```
TitleScore = sum(S_k) / n
TitleDemand = sum(D_k) / n
TitleTrend  = sum(T_k) / n
TitleGrowth = sum(G_k) / n
```

没有按搜索量加权，没有动态权重，也不对可能重叠的关键词搜索量求和为“标题搜索量”。综合量不输出关键词合计搜索次数。

即使历史不足，若最近/前期三个月分别完整，仍展示可确认的 r/p 和可计算的原始变化率；分项与分数保持 null。过期缓存数值可查看但不评分，并明确标注过期。异常或市场不匹配的数据不参与计算。真实零值、无数据、不支持、请求失败、过期五种状态单独保存。

浮点计算采用 Python 双精度、`statistics.fmean`，所有分项及关键词评分在计算聚合前保持精度；最终返回时用 `round(value,2)`（Python ties-to-even）保留两位，UI 格式化显示。关键词集合顺序不会改变等权聚合含义。单词数据、集合、地区/语言/设备、完整窗口、有效状态与公式版本相同时结果确定。是否处于允许的来源新鲜度区间也必须一致；同一个旧报告日后可能已不满足评分条件。Agent 换词或 API 更新会改变数据，不承诺同一标题永远同分。

## 可复核示例

H 全为 100：r=p=100，D≈40.09，T=50，G=50，S≈46.03。

前九个月 0、后三个月 10：D≈20.83，T=87.5，G=5.5，S≈36.23；原始百分比 null。低基数没有被当作“无限增长”。

前九个月 1000、后三个月 0：D=T=G=S=0，原始变化 -100%。

完整零值十二月：S=0。任何必需月份/设备缺失：S=null。少一个候选词的数据：TitleScore=null，已完整的其他词仍可显示各自评分。
